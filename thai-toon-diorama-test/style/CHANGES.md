# Thai Toon Diorama · การ์ตูนไทยในฉาก 3D — decisions

Made from a blank page; technique base 2.5D Pixel Art (`hd-2d`). "Base" is hd-2d's value, "—" where the thing is new.

| Section | Base (hd-2d) | Now | Why |
|---|---|---|---|
| Size | 1920×1080 | 1080×1920 | vertical series for TikTok / Reels / Shorts |
| §1 Essence, characters | flat low-res pixel sprites | flat vector cartoon cut-outs: round big head, hoodie, tube limbs, thick dark ink line | the user's own characters (grandma, kid, ghost) |
| §2 Set materials | pixel textures, Bayer ramps, NearestFilter | flat 3-step toon colour, drawn line detail, ink outline post pass on everything | no pixels; matches the characters' line |
| §2 Shadows | soft PCF | crisp PCF shadows | cartoon read |
| §2 Post | DOF + tilt-shift + strong bloom + heavy vignette | ink edges + light DOF + mild bloom + light vignette, no tilt-shift | faces must read on a phone |
| §3 Colour | cold ambient vs warm practicals | dusk mauve→peach home key + warm lamp; set cools and dims when the ghost appears; one hoodie colour per character | rural Thai dusk; horror-comedy switch |
| §4 Type | Cinzel / Cormorant serif, RPG dialogue box | Kanit Black/Bold + Mitr, thick ink outline, red EP pill, cartoon speech bubbles | Thai channel cover look |
| §5 Motion | stepped sprite frames 6–10 fps | instant pose swaps + 2-frame squash, mouth flaps, blink, breathing bob | sticker-cartoon acting |
| §6 Camera | always high, looking down, tilt-shift preciousness | eye level to slightly above; push-ins and snap zooms for gags | faces large enough to read |
| §7 Sound | chamber fantasy, storybook narrator | Thai rural instruments (phin, khaen, ranat, ching), cartoon foley, comic silence | genre and place |
| §8 Native moves | lights on / carried light / tilt preciousness / lights one by one / RPG / weather | kept: light on, shadows jump. New: the shadow that lies, ghost smoke, cover card, snap reaction | the style's signature for ghost comedy |
