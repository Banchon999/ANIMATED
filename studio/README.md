# studio — คลังชิ้นส่วนวิดีโอ 2.5D

Remotion + Three.js: ฉากเป็นสามมิติ ตัวละครเป็นแผ่น 2D ที่วางในฉากด้วยกล้องตัวเดียวกัน

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/lib.ts` | ฟอนต์ ตัวสุ่มแบบ seed กล้อง และการฉายจุดสามมิติลงจอ |
| `src/Character.tsx` | ตัวละครการ์ตูน: ท่าเดิน สีหน้า ชุด |
| `src/Tall.tsx` | ตัวละครสัดส่วนสูงสำหรับฉากกลางคืน |
| `src/Village.tsx` | ฉากหมู่บ้านกลางวัน |
| `src/NightRoom.tsx` | ฉากห้องนอนเรือนไม้กลางคืน |
| `src/Demo.tsx`, `src/Night.tsx` | คลิปตัวอย่างสองเรื่อง |
| `src/People.tsx` | เครื่องสุ่มคนจาก seed พร้อมคลังท่าทาง มือ ปาก สีหน้า |
| `src/Sets.tsx` | ชุดฉาก: แต่ละฉากวาดชั้นสามมิติ รับตัวละคร แล้วใส่เอฟเฟกต์แสงของตัวเอง |
| `src/Clip.tsx` | ตัวอ่านสคริปต์คลิป: แปลงไฟล์ JSON เป็นวิดีโอ |
| `clips/*.json` | สคริปต์คลิป หนึ่งไฟล์ต่อหนึ่งเรื่อง ลงทะเบียนใน `clips/index.ts` |
| `render.json` | คิวเรนเดอร์: รายชื่อคลิปที่ให้ GitHub Actions เรนเดอร์ |

## ใช้งาน

```sh
npm ci
npx remotion studio            # พรีวิว
npx remotion render Demo out/demo.mp4
```

แก้ `render.json` แล้ว push เพื่อสั่งเรนเดอร์บน GitHub Actions ไฟล์ MP4 อยู่ในหน้า Actions ของแต่ละรอบ

## มาตรฐานสัดส่วน (1 หน่วย = 1 เมตร)

ทุกฉากและของประกอบต้องยึดค่าเหล่านี้ และต้องถ่ายภาพคู่กับตัวละครก่อนเข้าคลัง

| สิ่งของ | ขนาด |
|---|---|
| คนผู้ใหญ่ | สูง 1.6–1.7 |
| ประตู | สูง 1.9–2.0 กว้าง 0.85 |
| ขอบล่างหน้าต่าง | สูงจากพื้น 0.9 |
| เพดานห้อง | 2.8 |
| ไม้กระดานผนังและพื้น | กว้าง 0.18–0.20 |
| เตียง | ยาว 1.9–2.0 ที่นอนสูง 0.55 เสามุ้ง 2.0 |
| ตู้เสื้อผ้า | สูง 1.9 |
| ใต้ถุนบ้านยกพื้น | 1.7–2.1 |
| ต้นไม้ | 5–8 ต้นตาลและมะพร้าว 9–12 |

ข้อควรจำเรื่องกล้อง: เฟรมแนวตั้งเห็นกว้างเพียงราว 0.56 เท่าของความสูง ห้องขนาดจริงจึงต้องถอยกล้องออกไป 9–10 เมตรที่ FOV 46–48 จึงจะเห็นกว้าง 4 เมตร

## เขียนคลิปใหม่เป็นข้อมูล

สร้างไฟล์ `clips/<ชื่อ>.json` แล้วเพิ่มใน `clips/index.ts` จะได้ composition ชื่อ `Clip-<id>` ดูตัวอย่างที่ `clips/sample.json`

| ช่อง | ความหมาย |
|---|---|
| `seed` | เลขสุ่มของคลิป เปลี่ยนเลขแล้วหมู่บ้านและมุมกล้องเปลี่ยน |
| `cast` | ตัวละคร: `seed` กับตัวเลือก `age` (child teen adult elder), `female`, `era` (old rural city) |
| `shots[].set` | `village` หรือ `room` |
| `shots[].cam` | `high` มุมสูง, `wide` กว้าง, `mid` กลาง, `close` โคลสอัป |
| `shots[].dur` | ความยาวช็อตเป็นวินาที |
| `shots[].focus` | ชื่อตัวละคร, `"a+b"` คือกึ่งกลางของหลายคน, หรือพิกัด `[x, y, z]` |
| `actors[].at` / `walkTo` | ตำแหน่ง `[x, z]` บนพื้น และจุดที่เดินไปตลอดช็อต |
| `actors[].pose` / `feel` | ชื่อท่าและสีหน้าจากคลังใน `People.tsx` |
| `actors[].then` | เปลี่ยนท่าหรือสีหน้าที่วินาที `at` ของช็อต |
| `actors[].face` | `1` หันขวา `-1` หันซ้าย |
| `caption` | บรรทัดซับที่ขึ้นทีละบรรทัด ใส่ `*คำ*` เพื่อเน้นสีเหลือง |
| `say` | ชื่อตัวละครที่ปากขยับ |
| `card` | การ์ดตัวเลขวิ่งนับ: `title`, `value`, `unit` |

ข้อจำกัดของเฟรมแนวตั้ง: ช็อต `mid` เห็นกว้างราว 1.9 เมตร ตัวละครสองคนจึงต้องยืนห่างกันไม่เกิน 1.3 เมตร ส่วนช็อต `wide` เห็นกว้างราว 4 เมตร
