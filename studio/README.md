# studio — คลังชิ้นส่วนวิดีโอ 2.5D

Remotion + Three.js: ฉากเป็นสามมิติ ตัวละครเป็นแผ่น 2D ที่วางในฉากด้วยกล้องตัวเดียวกัน

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/lib.ts` | ฟอนต์ ตัวสุ่มแบบ seed กล้อง และการฉายจุดสามมิติลงจอ |
| `src/Character.tsx` | ตัวละครการ์ตูน: ท่าเดิน สีหน้า ชุด |
| `src/Tall.tsx` | ตัวละครสัดส่วนสูงสำหรับฉากกลางคืน |
| `src/Village.tsx` | ฉากหมู่บ้านกลางวัน |
| `src/NightRoom.tsx` | ฉากห้องนอนเรือนไม้กลางคืน |
| `src/Accelerator.tsx` | ฉากโถงเครื่องเร่งอนุภาคโซเวียตยุค 70 (`ACCEL` เก็บพิกัดจุดสำคัญ) |
| `src/Clinic.tsx` | ฉากห้องคนไข้โรงพยาบาลยุค 70 (`CLINIC` เก็บพิกัดจุดสำคัญ) |
| `src/Fx.tsx` | เอฟเฟกต์รายช็อต: ลำแสง แสงวาบ ประกายไฟ เครื่องหมายคำถาม |
| `src/Demo.tsx`, `src/Night.tsx` | คลิปตัวอย่างสองเรื่อง |
| `src/People.tsx` | เครื่องสุ่มคนจาก seed พร้อมคลังท่าทาง มือ ปาก สีหน้า |
| `src/wardrobe-data.ts` | คลังเสื้อผ้า 3 ยุค (ข้อมูลล้วน) สีประจำยุค ลายผ้า ตัวสุ่มชุด และลายเซ็นชุด ใช้ทั้งตอนเรนเดอร์และใน `scripts/dress.mjs` |
| `src/Wardrobe.tsx` | วาดเสื้อผ้าแต่ละชิ้นในมุมหน้า หลัง ข้าง และทุกท่า |
| `src/WardrobeSheet.tsx` | แผ่นตรวจเสื้อผ้า composition `WardrobeSheet` |
| `scripts/dress.mjs` | แต่งตัวตัวละครหลักไม่ให้ชุดซ้ำ และจดชุดลง `wardrobe/used.json` |
| `src/Sets.tsx` | ชุดฉาก: แต่ละฉากวาดชั้นสามมิติ รับตัวละคร แล้วใส่เอฟเฟกต์แสงของตัวเอง |
| `src/Clip.tsx` | ตัวอ่านสคริปต์คลิป: แปลงไฟล์ JSON เป็นวิดีโอ |
| `clips/*.json` | สคริปต์คลิป หนึ่งไฟล์ต่อหนึ่งเรื่อง ลงทะเบียนใน `clips/index.ts` |
| `render.json` | คิวเรนเดอร์: รายชื่อคลิปที่ให้ GitHub Actions เรนเดอร์ |

## ใช้งาน

```sh
npm ci
npx remotion studio            # พรีวิว
npx remotion render Demo out/demo.mp4
```

แก้ `render.json` แล้ว push เพื่อสั่งเรนเดอร์บน GitHub Actions ไฟล์ MP4 อยู่ในหน้า Actions ของแต่ละรอบ

## เขียนคลิปใหม่เป็นข้อมูล

สร้างไฟล์ `clips/<ชื่อ>.json` แล้วเพิ่มใน `clips/index.ts` จะได้ composition ชื่อ `Clip-<id>` ดูตัวอย่างที่ `clips/sample.json`

| ช่อง | ความหมาย |
|---|---|
| `seed` | เลขสุ่มของคลิป เปลี่ยนเลขแล้วหมู่บ้านและมุมกล้องเปลี่ยน |
| `cast` | ตัวละคร: `seed` กับตัวเลือก `age` (child teen adult elder), `female`, `era` (old rural city), `outfit` (ดูตารางชุดด้านล่าง), `wear` และ `lead` (ดูหัวข้อเสื้อผ้า 3 ยุค) |
| `audio` | ไม่บังคับ: ชื่อไฟล์ใน `public/audio/` เล่นตั้งแต่เฟรมแรกจนจบคลิป |
| `shots[].set` | `village`, `room`, `accelerator` หรือ `clinic` |
| `shots[].cam` | `high` มุมสูง, `wide` กว้าง, `mid` กลาง, `close` โคลสอัป |
| `shots[].dur` | ความยาวช็อตเป็นวินาที |
| `shots[].focus` | ชื่อตัวละคร, `"a+b"` คือกึ่งกลางของหลายคน, หรือพิกัด `[x, y, z]` |
| `actors[].at` / `walkTo` | ตำแหน่ง `[x, z]` บนพื้น และจุดที่เดินไปตลอดช็อต (วาดเป็นมุมข้าง) |
| `actors[].gait` | ท่าเดิน: `stroll` ราว 1.2 ม./วินาที, `hurry` 2.8, `sneak` 0.9, `tired` 0.3 เลือกระยะเดินให้ใกล้เคียงความเร็วนี้คูณความยาวช็อต |
| `actors[].pose` / `feel` | ชื่อท่าและสีหน้าจากคลังใน `People.tsx` ท่านั่งนอน: `sit` นั่งเก้าอี้หรือขอบเตียง (ที่นั่งสูง 0.45 มือวางบนต้นขา), `sitfloor` นั่งขัดสมาธิบนพื้น มือวางบนเข่า, `lie` นอนหงาย (ดู `lieOn` `headDir`) ศีรษะลดลงตามความสูงจริง ลำแสง `through` จึงยังผ่านกลางศีรษะ |
| `actors[].then` | เปลี่ยนท่าหรือสีหน้าที่วินาที `at` ของช็อต |
| `actors[].face` | `1` หันขวา `-1` หันซ้าย |
| `actors[].view` | `front` (ค่าเริ่ม) หรือ `back` มองจากด้านหลัง: ไม่เห็นหน้า ผมคลุมศีรษะ แขนสลับข้างตามจริง ถ้ามี `walkTo` จะยังวาดเป็นมุมข้าง |
| `actors[].lieOn` | ใช้กับท่า `lie`: ความสูงของพื้นที่นอนเป็นเมตร ที่นอนบนเตียง 0.55 พื้น 0 (ค่าเริ่ม) `at` คือกึ่งกลางลำตัว |
| `actors[].headDir` | ใช้กับท่า `lie`: `1` ศีรษะไปทาง +x (ขวา, ค่าเริ่ม) `-1` ไปทาง −x ไม่ขึ้นกับ `face` |
| `actors[].eyes` | `open` หรือ `closed` บังคับตา ใช้ได้กับทุกสีหน้า ท่า `lie` หลับตาเองถ้าไม่ใส่ `open` |
| `actors[].stool` | ใช้กับท่า `sit`: `true` วาดเก้าอี้ไม้เตี้ยสูง 0.45 ใต้ตัวละคร (ฉากที่ไม่มีที่นั่ง) |
| `caption` | บรรทัดซับที่ขึ้นทีละบรรทัด ใส่ `*คำ*` เพื่อเน้นสีเหลือง |
| `say` | ชื่อตัวละครที่ปากขยับ |
| `card` | การ์ดตัวเลขวิ่งนับ: `title`, `value`, `unit` |
| `fx` | รายการเอฟเฟกต์ของช็อต ดูตารางเอฟเฟกต์ด้านล่าง |

### ฉาก

พิกัดเป็นเมตร `x` ซ้ายขวา `y` สูงจากพื้น `z` ระยะจากผนังหลังเข้าหากล้อง

| ฉาก | บรรยากาศ | ที่ยืนตัวละคร | จุดสำคัญ |
|---|---|---|---|
| `village` | หมู่บ้านกลางวัน | ลานกลางหมู่บ้าน | |
| `room` | ห้องเรือนไม้กลางคืน มืด | ข้างเตียงหน้ากล้อง | เตียง x −0.2..1.7, z 0.6..1.9 ที่นอนสูง 0.55 หมอนอยู่ทาง x 1.7 คนนอนบนเตียง: `"at": [0.68, 1.25], "pose": "lie", "lieOn": 0.55, "headDir": 1` |
| `accelerator` | โถงเครื่องเร่งอนุภาคโซเวียตยุค 70 พื้นและผนังคอนกรีตเทา โทนเทาอมเขียว สว่างพอให้ตัวละครเด่น โถงกว้าง 36 ม. (ผนังข้าง x ±18) สูง 8 ม. ผนังหลัง z −5 | x −1.8..1.8, z 2.0..4.0 | ท่อลำอนุภาคกลาง y 1.2, z 0.85 ที่ x 0 แล้วโค้งออกไปทั้งสองข้าง (วงแหวนรัศมี 28 ม.) แม่เหล็กสีน้ำเงินยาว 2.4 ม. สลับสีส้ม กินช่วง z 0.3..1.4 · แถบเหลืองดำบนพื้น z 1.95 · แผงควบคุม x −1.4, z 1.6 สูง 1.45 · หลอดไฟเตือนสีแดง (ดับ) `[-1.4, 1.5, 1.52]` · มุมแผงสำหรับประกายไฟ `[-0.88, 1.08, 1.72]` · กล่องสายไฟลายเหลืองดำ `[2.6, 1.05, 1.75]` · รางสายไฟบนผนังหลัง y 4.3 และ 5.1 · โคมห้อยเพดาน y 5.6 แถว z 1.0 |
| `clinic` | ห้องคนไข้โรงพยาบาลยุค 70 ผนังเขียวซีด บัวผนังล่างเขียวเข้มสูง 1.25 สว่าง เย็นนิด ๆ ห้องกว้าง 6.8 ม. (x ±3.4) เพดาน 2.8 ผนังหลัง z 0 | x −1.6..1.4, z 2.0..3.6 | เตียงเหล็กขาว x 0.2..2.1, z 0.5..1.5 ที่นอนสูง 0.55 หัวเตียงอยู่ทาง x 2.1 หมอน `[1.85, 0.62, 1.0]` · ตู้ยากระจก x −1.5, z 0.4 สูง 1.85 · แผ่นวัดสายตา `[-0.5, 1.6, 0]` · หน้าต่างแสงกลางวัน x 1.15 ขอบล่าง 0.9 กว้าง 1.1 สูง 1.3 · ประตู x −2.75 สูง 1.95 กว้าง 0.85 · โคมเพดาน `[0.2, 2.42, 2.2]` |

มุมกล้องในสองฉากใหม่: `wide` เห็นกว้างราว 4 เมตร `mid` ราว 1.9 `close` ราว 0.95 ส่วน `high` ใน `accelerator` มองลงจากเหนือหลังคาที่เปิดออกจนเห็นแนวโค้งของวงแหวน และใน `clinic` เป็นมุมสูงจากมุมห้องใต้เพดาน (เห็นกว้างราว 4.3 เมตร)

### ชุดแต่งกาย (`cast.<ชื่อ>.outfit`)

| ค่า | ผล |
|---|---|
| `labcoat` | เสื้อกาวน์ขาวแขนยาว ยาวถึงเข่า เปิดหน้า สวมทับเสื้อผ้าเดิม ทั้งท่ายืนและท่าเดินมุมข้าง (หมวก ผ้าสไบ และกระเป๋าถูกถอดออก) |
| `patient` | ชุดคนไข้สีฟ้าซีดเรียบ ๆ ยาวถึงเข่า แขนสั้น ขาเปล่า |

หน้า ผม สีผิว รูปร่าง ยังสุ่มจาก `seed` เหมือนเดิม

`labcoat` สวมทับชุดจากคลังเสื้อผ้า (ชั้นนอก หมวก กระเป๋า เป้ ผ้าขาวม้าคาดเอวถูกถอด) ส่วน `patient` แทนที่ชุดทั้งหมด

### เสื้อผ้า 3 ยุค (`cast.<ชื่อ>.wear`, `cast.<ชื่อ>.lead`)

ทุกคนได้ชุดสุ่มจาก `seed` ตามยุค เพศ และวัยของตัวเอง ชุดหนึ่งประกอบด้วยเสื้อ ท่อนล่าง รองเท้า และชั้นนอก หมวก เครื่องประดับ (ถ้ามี) พร้อมสีและลาย ถ้าต้องการกำหนดเองให้ใส่ `wear`

| ช่องใน `wear` | ความหมาย |
|---|---|
| `top` `bottom` `feet` | รหัสชิ้นจากตารางด้านล่าง (บังคับ) |
| `outer` `head` | ไม่บังคับ: ชั้นนอกหนึ่งชิ้น ของบนศีรษะหนึ่งชิ้น |
| `acc` | ไม่บังคับ: รายการเครื่องประดับ เช่น `["pakhaoma", "bag"]` |
| `colors` | ไม่บังคับ: สี `#rrggbb` ต่อช่อง `top` `top2` (สีลาย ขอบ หรือเสื้อยืดใต้เบลเซอร์) `bottom` `bottom2` (ตีนซิ่น ลายผ้าถุง แถบข้างกางเกงวอร์ม) `outer` `head` `acc` `feet` ช่องที่ไม่ใส่สุ่มจากสีประจำยุค |
| `pattern` | ไม่บังคับ: ลายเสื้อ `plain` สีพื้น, `stripes` ลายทาง, `check` ลายตาราง, `floral` ลายดอกเล็ก, `plaid` ลายผ้าขาวม้า |

ตัวอย่าง: `"wear": { "top": "mohom", "bottom": "kuay", "head": "ngob", "acc": ["pakhaoma"], "feet": "barefoot" }`

ทุกชิ้นต้องเข้ากับ `era` ของตัวละคร (`validateClip` ตรวจให้ และต้องใส่ `era` เมื่อมี `wear`) ตัวอักษร ญ / ช ท้ายชื่อคือชิ้นที่ตัวสุ่มเลือกให้เฉพาะผู้หญิง / ผู้ชาย แต่กำหนดเองใน `wear` ได้ทุกเพศ

| ชนิด | `old` สมัยก่อน | `rural` ชนบทปัจจุบัน | `city` เมืองปัจจุบัน |
|---|---|---|---|

กฎตัวละครหลัก: เสื้อผ้าของตัวหลักห้ามซ้ำข้ามคลิป (ตัวประกอบซ้ำได้) ใส่ `"lead": true` ให้ตัวหลัก แล้วรัน

```sh
node scripts/dress.mjs <id ของคลิป>
```

สคริปต์สุ่มชุดตามยุคของตัวหลักแต่ละตัวที่ยังไม่มี `wear` (seed จาก `seed` ของคลิปกับของตัวละคร) สุ่มใหม่จนลายเซ็นชุด (รหัสชิ้นเรียงตามตัวอักษร + สีเสื้อ ท่อนล่าง ชั้นนอก) ไม่ซ้ำกับใน `wardrobe/used.json` แล้วเขียน `wear` ลงไฟล์คลิป และต่อท้ายบันทึก `{ clip, who, signature, wear, date }` รันซ้ำได้ ชุดเดิมคงอยู่ ถ้าลบ `wear` ออกแล้วรันใหม่จะได้ชุดเดิมจากบันทึก ถ้าเขียน `wear` เองแล้วชนชุดที่เคยใส่ สคริปต์จะแจ้งว่าใครเคยใส่ในคลิปไหน ตัวหลักที่มี `outfit` จะได้ชุดที่ไม่มีชั้นนอกและหมวก (เพราะถูกเสื้อกาวน์บัง) การเรนเดอร์ไม่อ่านบันทึกนี้ ภาพจึงเหมือนเดิมทุกครั้ง ตัวหลักที่ยังไม่มี `wear` ทำให้ `validateClip` แจ้งข้อผิดพลาดพร้อมคำสั่งที่ต้องรัน

ผ้าซิ่น ผ้าถุง และผ้าโสร่ง ทำให้ท่าเดินก้าวสั้นลงราวครึ่งหนึ่ง (ความเร็วของ `gait` จึงลดลงตาม เท้ายังไม่ไถล) หมวกแข็ง (งอบ แก๊ป บักเก็ต) ถูกถอดเมื่อนอน

แผ่นตรวจ: composition `WardrobeSheet` แสดงยุคละ 6 ชุดบนคนต่างเพศต่างวัย และคนหนึ่งคนในมุมหน้า หลัง ข้างขณะเดิน นั่งเก้าอี้ และนั่งพื้น

### เอฟเฟกต์ (`shots[].fx`)

| ชนิด | ช่อง | ผล |
|---|---|---|
| `beam` | `through` ชื่อตัวละคร, `y`, `z`, `from` วินาที (ค่าเริ่ม 0), `strength` 0..1 (ค่าเริ่ม 1) | ลำแสงเส้นตรงแนวนอนเรืองสีฟ้าอมม่วงพาดทั้งจอ แกนสว่างบาง รัศมีฟุ้ง และประกายเล็ก ๆ วิ่งไปตามลำ วาดทับตัวละคร ถ้าใส่ `through` ลำแสงจะผ่านกลางศีรษะของตัวละครนั้นพอดีตามตำแหน่ง ท่า (รวมท่านั่งยอง) และส่วนสูง ถ้าไม่ใส่จะอยู่ที่ `y` `z` (ค่าเริ่ม 1.2 และ 0.85 คือแนวท่อในฉาก `accelerator`) |
| `flash` | `at` วินาที (ค่าเริ่ม 0) | แสงวาบสีขาวเต็มจอ ขาวสุดใน 2 เฟรม ค้างราว 0.25 วินาที แล้วจางหายในราว 1 วินาที (อยู่ใต้ซับ) |
| `sparks` | `at` `[x, y, z]` | ประกายไฟฟ้าเล็ก ๆ กะพริบที่จุดนั้น เช่น `[-0.88, 1.08, 1.72]` มุมแผงควบคุม |
| `question` | ไม่มี | เครื่องหมายคำถามจาง ๆ ขนาดใหญ่ลอยอยู่หลังศีรษะตัวละครที่พูด (`say`) หรือตัวที่กล้องโฟกัส วาดใต้ตัวละคร |

ตัวอย่าง: `"fx": [{ "kind": "beam", "through": "bugorski", "from": 0.4 }, { "kind": "flash", "at": 0.4 }]`

โค้ดที่ต้องการความสูงศีรษะใช้ `headHeight(spec, pose)` หรือ `headCenter(spec, pose)` จาก `People.tsx` ท่านอนส่ง `{ on, dir }` เป็นอาร์กิวเมนต์ที่สาม ภาพตรวจท่าทั้งหมดอยู่ใน composition `PoseSheet`

ข้อจำกัดของเฟรมแนวตั้ง: ช็อต `mid` เห็นกว้างราว 1.9 เมตร ตัวละครสองคนจึงต้องยืนห่างกันไม่เกิน 1.3 เมตร ส่วนช็อต `wide` เห็นกว้างราว 4 เมตร

สคริปต์ถูกตรวจอัตโนมัติด้วย `validateClip` ตอนโหลด: ชื่อท่า ฉาก ตัวละคร หรือระยะห่างที่เกินเฟรม จะแจ้งข้อผิดพลาดพร้อมเลขช็อต ตรวจได้ด้วย `npx remotion compositions`

`render.json` มีช่อง `run` ไว้เพิ่มเลขเมื่อต้องการสั่งเรนเดอร์คลิปเดิมซ้ำ เพราะ Actions เริ่มเมื่อไฟล์นี้เปลี่ยนเท่านั้น
